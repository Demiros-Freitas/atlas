# Demiros Tools · Atlas

Módulo para Foundry VTT (v13–v14): mapas do mundo, locais, rotas, viagens de grupos com tempo e terreno, névoa de exploração, portais e mundos que dão a volta (globo e anel). Funciona sozinho; com o **Cronos** ganha o céu, as luas e o calendário do mundo.

## Instalar
No Foundry, em **Módulos → Instalar módulo**, cole o manifesto:

```
https://github.com/Demiros-Freitas/atlas/releases/latest/download/module.json
```
